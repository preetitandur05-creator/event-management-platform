# Event Management Platform

Reusable full-stack Event Management Website for **SAMANVAYA 2027** — Next.js, Prisma, Neon, Resend. Student-friendly deploy to Vercel.

## Features

- Public event site (home, agenda, sponsors, about, contact, register)
- Ticket registration with QR code
- Admin dashboard (login, overview)
- Email notifications via Resend
- Prisma + Neon Postgres
- NextAuth authentication
- Ready for Vercel deployment

## Quick Start

1. Clone the repo
2. Copy `.env.example` to `.env.local` and fill values
3. `npm install`
4. `npx prisma migrate dev`
5. `npm run dev`

## Deploy to Vercel

1. Push to GitHub
2. Import in Vercel
3. Set environment variables
4. Deploy

See full docs in the original project structure.
